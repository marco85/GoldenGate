# pearOS components in GoldenGate

Pear Dock is built from https://github.com/pearOS-archlinux/pkgbuilds at commit `a82d2a476b165f8921dfc84b0eb805d40462d9b0`, directory `pearos-dock` (package 26.6.10-5). Upstream credits Alexandru Balan and Victor Calles; metadata declares GPL-2.0-or-later. Existing copyright and embedded icon notices are preserved. Complete original source is included under `/usr/share/goldengate/sources` in the image; the pinned build script is in this repository.

The dock uses GoldenGate's existing Plasma panel, restrained magnification, dark skin and standard application launchers. Stock Plasma task management remains a fallback. GoldenGate removes the hardwired Nautilus/Pinder and folder-arc integrations through an included patch; Dolphin remains the file manager. The launcher and trash use stock Plasma widgets. The QML module build is corrected to install distinct backing and generated plugin libraries. No pearOS package repository, settings replacement, installer or patched system libraries are enabled. Distribution-specific settings dependencies and destructive install behavior are intentionally excluded.
